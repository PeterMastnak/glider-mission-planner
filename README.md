# Glider Mission Planner

Plan uncrewed surface vehicle (glider) missions to acoustic receivers from Carmel to Año Nuevo: shortest water routes around land, receiver keep-out circles and kelp, live currents/wind/waves (Open-Meteo), go/no-go checks, best launch time, battery estimate, printable plan sheet, and operator exports.

Live: https://petermastnak.github.io/glider-mission-planner/
