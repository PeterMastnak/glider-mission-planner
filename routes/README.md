# Team routes

Every `.json` file in this folder shows up under **Team routes** in the Glider Mission Planner for everyone who opens it.

- **Add a route:** in the planner, save a route, then press **Share with team** under My routes. GitHub opens with the file filled in; press **Commit changes**. It appears for everyone within a few minutes.
- **Remove or rename a route:** open its file here (or press **GitHub** next to it in the planner) and delete or edit it.

Only people with write access to this repository can add, change or delete team routes. Anyone can open them.
